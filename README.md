# React Todo List

A simple Todo List application built using React to demonstrate the fundamentals of modern frontend development. The project showcases React's component-based architecture, state management using the `useState` hook, event handling, and dynamic rendering of data through an interactive user interface.

## Features

- Add new tasks
- Display tasks dynamically
- Automatically clear the input field after adding a task
- Responsive and user-friendly interface
- Real-time updates using React state

## Technologies Used

- React
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite

## Project Overview

This application allows users to create and manage a list of tasks through a simple and intuitive interface. The project uses React's `useState` hook to manage both the input field and the task list. Whenever a task is added, the application updates the state and re-renders the interface automatically without refreshing the page.

## React Concepts Used

- Functional Components
- JSX
- useState Hook
- Event Handling
- State Management
- Rendering Lists with `map()`
- Component Re-rendering

## Installation

1. Clone the repository.

```bash
git clone https://github.com/your-username/todo-list.git
```

2. Navigate to the project directory.

```bash
cd todo-list
```

3. Install the dependencies.

```bash
npm install
```

4. Start the development server.

```bash
npm run dev
```
